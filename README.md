ModelX Competition Project

This repository contains the code, preprocessing pipeline, model training scripts, and output visualizations for our team's (JRM65) machine learning competition submission.

=>Project Structure

modelX/

=> Setup Instructions
1. Create and activate the virtual environment
python3.11 -m venv venv
source venv/bin/activate   # Mac/Linux
venv\Scripts\activate      # Windows

2. Install dependencies
pip install -r requirements.txt

3. Run the main training script
python training_multiple_models.py

=> Data

dataset.csv – main input dataset

selected_data.csv – filtered/cleaned dataset (generated by data_selection.py)

=> Scripts Explanation

data_selection.py
Performs data cleaning, column filtering and saves selected_data.csv.

training_multiple_models.py
Trains multiple ML models, compares accuracy, plots confusion matrices, ROC curves, feature importance, and saves PNG results.

selected_model.py
Loads the best-performing model.

=> Output Files

Running the main script will generate:

best_model_confusion_matrix.png

best_model_feature_importances.png

model_roc_curves.png

model_accuracy_comparison.png

Saved automatically in the root folder.

=> Requirements

The project uses Python 3.11.14.
All dependencies are listed in requirements.txt.

=> Reproducibility Notes

To reproduce identical results:

Use Python 3.11.14

Run inside a fresh virtual environment

Ensure the same dataset version is used
